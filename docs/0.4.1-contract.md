## 2. 数据真实性：`quotaKind` 契约

`MetricWindow.quotaKind` 四态，`usedPercent` / `remainingPercent` 现在都是**可选**：

| kind | 何时使用 | 百分比 | UI 呈现 |
|---|---|---|---|
| `usage` | 上游给出真实配额比例（5h / weekly / monthly / rolling / 余额按官方比例） | 必须同时给 `usedPercent` 与 `remainingPercent`，且来自上游数值 | 进度环/条 + 百分比 |
| `balance` | 上游只给金额/积分 | **禁止**填写百分比（无论金额多少） | `amountText` 金额；无金额时显示「—」 |
| `liveness` | 只验证了鉴权/连通性（`/models`、`/user` 等 200） | **禁止**填写百分比 | 「已连接 · 未提供额度接口」；卡片 `status` 保持 `ok`，但**不得**出现「额度充足」或绿色满环 |
| `unknown` | 上游 200 但配额字段缺失/无法解析 | **禁止**填写百分比 | 「—」/「额度状态未知」 |

统一工具（`src/core/types.ts`）：
- `windowQuotaKind(win)`：缺省时，有 `remainingPercent` 视为 `usage`，否则 `unknown`。
- `isQuantified(win)`：仅当 kind 为 `usage` 且两个百分比都是有限数字时为 true。**所有**需要百分比的消费方（渲染、历史、告警、burn rate、Agent 摘要、排序）都必须先过这个判断。

绝对禁止的写法：`?? 0`、`|| 0`、`Number(x)` 直接作用于可能为 `null` 的百分比字段、用金额阈值编造百分比（如 `<5 → 15%`）。

## 3. 状态语义

- `status: 'error'` 只用于**凭据/网络不可用**（401/403/超时/连接失败）。
- 余额为 0、额度耗尽 → `warn` 或窗口 `exhausted`，**不是** `error`。
- 窗口 `status: 'unknown'` 时不得产出百分比、不得进入历史/告警。

## 4. provider 改造清单（P 轨道）

每家 provider 必须满足：
1. 只在上游返回真实比例时设 `quotaKind: 'usage'` + 两个百分比；
2. 余额类（Kimi / SiliconFlow / DeepSeek）→ `quotaKind: 'balance'` + `amountText`，删除编造百分比；
3. 纯连通性（GLM / MiniMax / Qwen / Volcengine / Copilot / Claude）→ `quotaKind: 'liveness'`，窗口不设百分比，`subtitle` 说明「仅连通性」；
4. `null`/缺失字段 → `quotaKind: 'unknown'`，不设百分比，不设 `exhausted`；
5. 透传 `config.proxyMode` 到 `fetchWithProxy`（第 5 个参数），全 16 家一致；
6. 请求超时统一走 `fetchWithProxy` 的 timeout，不再裸 `fetch`；
7. `openai_billing`：查不到 usage 就 `unknown`，不得恒 100%；
8. `custom_api`：分母用 `total_granted` / `quota` 原始总额；余额 0 就是 0%（`usage` 比例仅在总额已知时成立），0 余额不得回退成满额；
9. Antigravity：`remainingFraction` 为 `null`/缺失 → `unknown`，不得 `Number(null)=0`；
10. Codex / Cursor / OpenCode-Go：字段缺失 → `unknown`，不得 `?? 0`。

每家 provider 至少补 3 个 fixture 断言：正常 / 字段缺失 / 401 或 429。

## 5. 安全契约（Lead 轨道）

- 所有 `/api/dsh-quota/*` 路由前置守卫：
  - `Origin`（存在时）必须是同源；`Sec-Fetch-Site` 存在时只允许 `same-origin`/`none`；
  - `POST` 必须 `Content-Type: application/json`（否则 415），强制触发 preflight；
  - 要求自定义头 `X-DSH-Quota: 1`（客户端统一带上）；
  - 不满足 → 401/403。
- `custom_api` / `openai_billing` 的 `baseUrl`：仅 http/https；拒绝 loopback/私网/link-local/`169.254.169.254`/`.internal`；DNS 解析后再按 IP 校验。
- `restoreMaskedSecrets`：当 `baseUrl` / `httpProxy` / `provider` 发生变化时**不得**回填旧密钥，要求用户重填。
- `getSafeConfig`：`keyProps` 与 secrets 字段清单共用；掩码固定字符，不回显真实首尾字符。

## 6. 持久化契约（C 轨道）

- 单 key 上限真正生效（`splice`）；默认 30 天保留。
- 写入：dirty 标记 + ≥10 分钟 debounce + 紧凑 JSON；`save()` 移出请求路径（独立 ticker 或异步）。
- 损坏文件：先 `rename` 成 `.corrupt-<ts>`，再重建；保留 `.bak` 最近一份。
- 0.4.1 目标：写放大 ≤ 1 GB/天（30 天数据 ≤ 26 MB 时），单次保存不阻塞 event loop > 50 ms。
- 并发：`getQuotaCards` 单飞（同实例 + 整轮），`force` 限流 ≥5 s；`fetchCard` 接受 `AbortSignal` 并透传；失败指数退避（60s→…→10min）。

## 7. 客户端契约（U 轨道）

- 所有 `fetch` 带 `AbortSignal.timeout(8000)` 与 `X-DSH-Quota: 1` 头。
- `refreshSingle` 结果必须过 `escapeCardText`；`emit()` 逐 listener try/catch。
- 渲染 `isQuantified(window)` 为 false 时不显示百分比/进度环：`balance` 显示金额，`liveness` 显示「仅连通性」，`unknown` 显示「—」。
- 渲染前保存并恢复容器 `scrollTop`；焦点在输入控件（或存在 dirty 标记）时跳过重建。
- 静默轮询失败要保留 `error` 并在头部展示「最后更新 hh:mm + 失败」；`document.hidden` 时暂停轮询与 HUD 轮播。

## 8. 构建契约（Lead 轨道）

- 客户端产物必须仍是 **classic script + IIFE + 单 id**（`@francescoli/dsh-quota`），重复执行幂等；
- 宿主产物为 ESM，保留全部命名导出（`tests/run.mjs` 依赖）；
- 两者都由 esbuild 生成，并输出 `.map`；
- 构建脚本自带闸门：语法可解析、IIFE 外无裸声明、`__ModuleLoader__.load` 恰好一次且 id 等于包名。
